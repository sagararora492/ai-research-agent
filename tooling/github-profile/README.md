## Featured project

### Fieldnotes · Agentic Research Assistant

A Python research assistant with a local web studio and CLI. It plans research, collects sources, checks citations, and saves the evidence alongside the brief.

- Configurable research agents and model profiles.
- Offline document research with no API keys required.
- Optional live search and model synthesis.
- Explicit evidence gaps, provider warnings, and citation checks.
